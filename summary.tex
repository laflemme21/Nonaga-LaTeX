The primary aim of this project was to design, implement, and optimize a high-performance computational engine and Artificial Intelligence (AI) agent for the abstract board game Nonaga. To achieve an advanced level of play and facilitate rapid algorithmic experimentation, the project was structured around three core technical objectives:

\begin{enumerate}
    \item \textbf{High-Performance Engine Development:} To engineer a highly optimized rule engine and state generator to maximize state evaluations per second while avoiding the performance bottlenecks of object-oriented representations.
    \item \textbf{Adversarial AI Implementation:} To develop a robust AI opponent utilizing Minimax.
    \item \textbf{Automated Parameter Optimization:} To construct a Genetic Algorithm framework that utilizes self-play tournaments to autonomously tune the AI overcoming the limitations of manual heuristic configuration.
\end{enumerate}

The resulting system successfully integrates these components with an interactive PyGame graphical interface, providing both a seamless user experience for human-vs-AI gameplay and a powerful backend for continued heuristic optimization and profiling.
