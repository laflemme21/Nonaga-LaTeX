This project presents the design, implementation, and empirical evaluation of Nonaga-Online: a high-performance computational engine and adversarial AI agent for the abstract strategy board game Nonaga. Three core technical challenges are addressed. First, a custom hexagonal bitboard engine was implemented in C and exposed to Python via a Cython bridge, replacing an object-oriented pure-Python predecessor and achieving a 64--88$\times$ improvement in nodes evaluated per second, sufficient to make real-time depth-3 adversarial search feasible for the first time. Second, an iterative-deepening minimax search with alpha-beta pruning and a Zobrist-hashed transposition table was developed, reducing the depth-3 node count from 82 million (brute force) to approximately 1.15 million, a combined $72\times$ reduction, and bringing decision latency from 49 seconds to under one second in steady-state play. Third, a Genetic Algorithm framework employing roulette wheel selection, arithmetic crossover, and a novel $k$-opponent circulant tournament fitness function was constructed to autonomously optimise the eight-parameter evaluation function. The resulting system supports real-time human-versus-AI gameplay through a PyGame interface and serves as a platform for continued heuristic experimentation. The project demonstrates that a custom bitboard architecture, even for a non-standard hexagonal geometry with no prior Nonaga-specific literature, can yield order-of-magnitude engine performance gains, and that principled adversarial search optimisation transforms an otherwise computationally intractable problem into one viable for interactive play.
